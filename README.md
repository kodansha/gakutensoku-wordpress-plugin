# Gakutensoku WordPress Plugin

## 概要

[楽転即](https://gakutensoku.com/)の利用者向けに、記事フィードを楽転即スキーマ準拠の JSON 形式で REST API 経由で取り込み・配信するための WordPress プラグインです。

### 主な機能

- 楽転即スキーマ準拠の REST API フィード（`/gakutensoku/v1/feed`）の提供
- 配信先プラットフォームごとのカスタムフィールド
- 投稿ごとのプラットフォーム別配信設定・除外設定
- クレジット表示用の Gutenberg ブロック
- ページネーション用の Gutenberg ブロック
- 記事本文中の除外範囲を指定するブロック・エディタ拡張（Gutenberg / Classic Editor 両対応）
- 配信設定用のメタボックス
- 管理画面の設定ページ（配信先プラットフォーム、概要の設定方法、アイキャッチ画像URLの設定方法など）

## 動作要件

- WordPress 5.8 以上
- PHP 7.4.27 以上

## インストール

1. [Releases](../../releases) から最新版の `gakutensoku-wp.zip` をダウンロードします。
2. 以下のいずれかの方法でプラグインを追加します。
   - WordPress管理画面の「プラグイン」→「新規追加」→「プラグインのアップロード」から、ダウンロードした zip ファイルをアップロードします。
   - ダウンロードした zip ファイルを `wp-content/plugins/` ディレクトリ内に直接展開します。
3. プラグインを有効化します。
4. 「設定」→「外部配信（楽転即）」から、配信先プラットフォーム・概要の設定方法・アイキャッチ画像URLの設定方法など初期設定を行います。

## 使い方

有効化・設定後、以下の URL から楽転即スキーマ準拠のフィードを確認できます。URL の形式は、WordPress の「設定」→「パーマリンク」の設定によって異なります。

- パーマリンク設定が「基本」以外の場合: `https://{サイトのドメイン}/wp-json/gakutensoku/v1/feed`
- パーマリンク設定が「基本」の場合: `https://{サイトのドメイン}/?rest_route=/gakutensoku/v1/feed`

各投稿の配信設定は、投稿編集画面のメタボックス「外部配信（楽転即）」から行います。
